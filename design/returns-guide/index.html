A one-minute overview

Start with an eligible order

Delivered, inside your return window and with units still available. The initial window is 30 calendar days.

One product, multiple units

Bought 2 and requested 1? The other unit can have its own request. Pending, approved and received units stay committed.

A simulation from start to finish

Approval means prepare the products for a fictional pickup within three business days. No real carrier or refund.

Why can the same product appear in another return?

Availability is calculated per order item: purchased units minus units in pending, approved and received requests. Rejected or cancelled requests release their units. The order must still meet the return window and delivery rules.

2 units purchased−1 unit committed=1 unit available
