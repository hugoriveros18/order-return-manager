# Order Returns Manager — Demo Product Catalog

Ten fictional technology and desk-accessory products. Prices are sample USD retail prices and specifications are fictional.

- `products.json`: array of ten product records.
- `images/`: one optimized 1024 × 1024 WebP image per product.
- `image` values are relative to this catalog folder.

Images are intended for demo use; they are AI-generated, not photographs of manufactured products.
